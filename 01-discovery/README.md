# O que é o software

O Xournal++ é um software para anotações à mão livre que oferece suporte a anotações em arquivos PDF. Desenvolvido em C++ com GTK3, é compatível com Linux (por exemplo, Ubuntu, Debian, Arch, SUSE), macOS e Windows 10. Oferece suporte a entrada por caneta a partir de dispositivos como mesas digitalizadoras Wacom.

## Problema que o software resolve
O software se propõe a ser rápido, flexível e funcional, na prática, resolve necessidades como:

**• Anotar sobre PDFs:** permite selecionar texto do PDF de fundo, copiar, destacar, sublinhar ou riscar além de seguir links do documento.

**•	Substituir o caderno de papel e apps pagos:** é uma alternativa de código aberto a apps proprietários como OneNote e GoodNotes, sem custo de assinatura.

**•	Exportação:** SVG, PNG e PDF pela interface ou linha de comando.

## Público-alvo e principais usuários
É amplamente usado no meio acadêmico por estudantes, professores e educadores além de profissionais do ramo de engenharia, design e pesquisa. 

Os usuários utilizam do programa para anotar slides de aula, resolver problemas de matemática, fazer diagramas direto no tablet, esboçar ideias, marcar projetos, criar notas manuscritas, dentre outras atividades.

## Principais funcionalidades
Algumas das funcionalidades presentes no software são: 

•	Suporte a canetas sensíveis à pressão e mesas digitalizadoras (por exemplo, tablets da Wacom, Huion, XP Pen, etc.)

•	Planos de fundo que simulam papel para anotações, rascunhos ou uso como quadro branco

•	Anotações sobre arquivos PDF

•	Seleção de texto em um PDF de plano de fundo, com opções para copiar, destacar, sublinhar ou riscar

•	Acesso a links presentes no PDF de plano de fundo

•	Exportação para diversos formatos, incluindo SVG, PNG e PDF, tanto pela interface gráfica quanto pela linha de comando

•	Diversas ferramentas de desenho (como caneta e marca-texto) e estilos de traço (como contínuo ou pontilhado)

•	Desenho de formas geométricas (linhas, setas, círculos, retângulos, curvas/splines)

•	Uso de esquadro e compasso para medições ou como guia para desenhar linhas retas, arcos circulares e raios

•	Funcionalidade de preenchimento de formas

•	Redimensionamento e rotação de formas

•	Rotação e ajuste a uma grade (grid snapping) para o alinhamento preciso de objetos

•	Estabilização de traço para uma escrita ou desenho mais fluido

•	Ferramenta de texto para adicionar conteúdo com diferentes fontes, cores e tamanhos

•	Suporte aprimorado para a inserção de imagens

•	Borracha com múltiplas configurações

•	Suporte a LaTeX (requer uma instalação funcional de LaTeX), incluindo modelos personalizáveis ​​e um editor com redimensionamento e destaque de sintaxe

•	Barra lateral com pré-visualização de páginas, recursos avançados de organização, marcadores de PDF e camadas (que podem ser ocultadas ou editadas individualmente)

•	Possibilidade de atribuir diferentes ferramentas, cores, etc., aos botões da caneta ou do mouse

•	Barra de ferramentas personalizável com diversas configurações (por exemplo, otimizada para orientações retrato ou paisagem)

•	Suporte a paletas de cores personalizadas no formato .gpl

•	Definição de modelos (templates) de página

•	Ferramentas para relato de erros, salvamento automático e backup automático

•	Gravação e reprodução de áudio sincronizadas com anotações feitas à mão

•	Suporte a múltiplos idiomas (mais de 20 idiomas disponíveis)

•	Suporte a plugins via scripts em Lua
